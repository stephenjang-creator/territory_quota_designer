Territory & Quota Designer

Quota-first capacity planning. Each rep's quota is standardized by role (same title + segment → same number) and set from pay — quota = a multiple of OTE. Territories are then carved back from those quotas: each book is packed with enough pipeline to give the rep a fair shot at their number. Reps a segment can't cover show up as a capacity gap. Dollar figures are USD (annual contract value), shown in thousands ($K). Sample data. · API
